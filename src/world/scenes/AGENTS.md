# Regole per `src/world/scenes/`

Prima di modificare questo dominio, leggi integralmente
[`docs/world/scenes.md`](../../../docs/world/scenes.md).

- Il campionario riusa il vocabolario esistente: non introduce geometria,
  materiali, palette o tipi di superficie.
- Layout e sagoma hanno una sola fonte; misure e dettaglio si ricavano dal
  comportamento reale, non da tabelle duplicate.
