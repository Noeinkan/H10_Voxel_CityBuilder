# Ragionamento delle fasi chiuse

Una scheda per fase conclusa: obiettivo esteso, vincoli, gate, come è stata
risolta e cosa ha insegnato. È la parte di [ROADMAP.md](../../ROADMAP.md) che
serve **a domanda** — quando si vuole sapere perché una cosa è fatta così — e
non mentre si guarda cosa resta da fare.

Le attività, con il loro stato e le loro etichette, restano tutte in radice: la
dashboard legge solo quel file, e una scheda non ne sposta nessuna. Le fasi che
qui non compaiono sono quelle ancora aperte, che restano intere in radice.
