# Archivio del changelog

Il changelog in radice tiene gli ultimi 13 incrementi; tutto quello che li precede sta
qui, in schede numerate dalla piu’ vecchia. Un incremento archiviato non cambia mai
scheda, e la scheda alta e’ la sola che cresce: si apre una scheda nuova quando
l’ultima supera i 55.000 caratteri, che e’ quanto se ne legge in un colpo solo.

**Cerca qui, poi apri una scheda sola.** Il titolo dice quasi sempre se e’ l’incremento
giusto; per il testo, `rg -n "<termine>" docs/changelog/` lo trova senza aprirne nessuna.
